# Review: declare `http:lan` for a LAN ERP (ut-docs#3794) — v1.2.0

Date: 2026-10-07 · Lane: lane:cloud-24 · Written by Opus 5.5, reviewed by Fable in a fresh context.

## What shipped
- `manifest.json`: `http:lan` added next to `net:*` and `net:@setting:endpoint_url`; version
  1.1.0 → 1.2.0. The till now requires `http:lan` for any http request to a LAN address, on top of
  the exact grant (ADR-0121 §3, owner decision ut-docs#3794, universal-till `wasm_egress.go`).
- `scripts/validate.sh` requires `http:lan`; README and CLAUDE.md describe the new rule.
- Released tills accept the manifest: `http:lan` is on the till's permission allow-list in every
  tag that has one (since ut-docs#3328); earlier tills accept any string.
